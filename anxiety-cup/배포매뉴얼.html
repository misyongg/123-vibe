다른 상담교사에게 배포할 때 이 문서 순서대로 따라 하세요. 예상 소요 시간: 처음 설정 30~40분

01폴더 구성

배포할 때 아래가 함께 있어야 합니다.

anxiety-cup/              ← 이 폴더만 배포해도 됩니다
├── index.html            ← 학생용 앱
├── 불안의파도타기.html    ← 선생님용 앱
├── emptycup.png          ← 종이컵 이미지 (필수)
├── paper.png             ← 쪽지 이미지 (필수)
├── config.js             ← 참고용 (실제 설정은 HTML 안)
└── 배포매뉴얼.md          ← 이 문서

google-apps-script/       ← 시트 연동 (별도 폴더)
├── anxiety-cup-Code.gs
└── anxiety-cup-README.md
⚠️ emptycup.png, paper.png가 anxiety-cup 폴더 안에 있어야 컵·쪽지가 보입니다.

03STEP 1 · Google 스프레드시트 만들기

  1. Google 스프레드시트 접속
  2. 빈 스프레드시트 새로 만들기
  3. 이름 예: 불안 종이컵 기록

이 시트에 학생 쪽지와 상담 기록이 쌓입니다. 본인 Google 계정으로 만드세요.

04STEP 2 · Apps Script 연결

  1. 시트에서 확장 프로그램 → Apps Script 클릭
  2. 기본 Code.gs 내용 전부 삭제
  3. google-apps-script/anxiety-cup-Code.gs 내용 전부 복사해서 붙여넣기
  4. 저장 (프로젝트 이름: 불안종이컵 등)
  5. 배포 → 새 배포 클릭
  6. 종류: 웹 앱 선택
  7. 설정:
    • 다음 사용자 인증 정보로 실행: 나
    • 액세스 권한이 있는 사용자: 모든 사용자
  8. 배포 → 웹 앱 URL 복사
    형식: https://script.google.com/macros/s/...../exec

확인

브라우저에 URL 붙여넣기 → 아래처럼 보이면 성공:

{"ok":true,"service":"anxiety-cup"}

05STEP 3 · 앱에 URL·비밀번호 넣기

아래 두 파일을 메모장·VS Code 등으로 엽니다.

  • anxiety-cup/index.html
  • anxiety-cup/불안의파도타기.html

각 파일 아래쪽에 있는 ANXIETY_CUP_CONFIG를 수정합니다.

const ANXIETY_CUP_CONFIG = {
  GOOGLE_SHEETS_URL: "STEP2에서_복사한_URL",
  TEACHER_PASSWORD: "원하는_비밀번호"   // 예: abc12345 (학생에게 알리지 마세요)
};
항목설명
GOOGLE_SHEETS_URLSTEP 2에서 복사한 Apps Script URL
TEACHER_PASSWORD선생님용 앱 입장 비밀번호 (본인만 알기)
⚠️ config.js만 수정해도 적용 안 됩니다. 반드시 HTML 두 파일을 수정하세요.

06STEP 4 · 인터넷에 올리기 (GitHub Pages 권장)

학생이 폰으로 쓰려면 웹 주소가 필요합니다.

4-1. GitHub 계정 준비

GitHub 가입 (없으면)

4-2. 새 저장소 만들기

  1. New repository → 이름 예: anxiety-cup-school
  2. Public 선택 → Create

4-3. 폴더 업로드

  1. 저장소에서 Add file → Upload files
  2. 아래 구조가 되도록 업로드: 
    anxiety-cup/          (폴더 통째로 — 이미지 포함)
    또는 저장소 루트에 anxiety-cup 폴더만 올려도 됩니다.
  3. Commit

4-4. GitHub Pages 켜기

  1. 저장소 Settings → Pages
  2. Source: Deploy from a branch
  3. Branch: main / / (root) → Save
  4. 1~2분 후 주소 확인: https://본인아이디.github.io/anxiety-cup-school/

4-5. 최종 URL

용도주소
학생용https://본인아이디.github.io/anxiety-cup-school/anxiety-cup/
선생님용https://본인아이디.github.io/anxiety-cup-school/anxiety-cup/불안의파도타기.html

학생에게는 학생용만 QR·링크로 공유하세요.

07STEP 5 · 사용 방법 (운영)

학생

  1. 학생용 링크 접속
  2. 별칭 입력 (예: 파란구름) — 실명 불필요
  3. 감정·생각·상황 적고 쪽지 넣기
  4. 같은 기기에서 별칭·쪽지 개수 기억됨

선생님

  1. 선생님용 링크 접속 → 비밀번호 입력
  2. STEP 1 학생 별칭 입력 → 종이컵 뒤집기
  3. STEP 2 불안 분류 (다룰 수 있음 / 없음)
  4. STEP 3 상담 상자·강물로 보내기
  5. STEP 4 DBT 연습 선택 → 오늘 상담 마무리
  6. 상담 마무리 후 학생 앱 새로고침 → 컵 비워짐

쪽지는 상담 마무리까지 하면 시트에서 처리완료되고, 다음 상담에는 새 쪽지만 불러옵니다.

08STEP 6 · 테스트 체크리스트

  • Apps Script URL 열면 {"ok":true,"service":"anxiety-cup"} 표시
  • 학생용에서 쪽지 1장 제출 → 시트 불안종이컵기록 탭에 행 추가
  • 선생님용 비밀번호로 입장 가능
  • 별칭 필터 후 쪽지 쏟기 가능
  • 상담 마무리 → 상담연동기록 탭에 저장
  • 학생 앱 새로고침 후 컵 비움

09시트 탭 설명

불안종이컵기록

학생이 넣은 쪽지 (저장시각, 별칭, 감정, 생각, 상황, 처리완료, noteId)

  • 처리완료: 상담 마무리 시 Y — 다음 상담에는 안 불러옴

상담연동기록

상담 마무리 시 분류·DBT·소감 메모

10자주 하는 실수

증상해결
컵·쪽지 이미지 안 보임anxiety-cup/emptycup.png, paper.png가 같은 폴더에 있는지 확인
쪽지가 시트에 안 쌓임GOOGLE_SHEETS_URL HTML에 넣었는지, Apps Script 새 배포 했는지
선생님 앱에서 쪽지 0장학생 별칭이 시트와 똑같은지 (띄어쓰기 포함)
상담 후에도 학생 컵 그대로학생 앱 새로고침; Apps Script 최신 코드 새 배포
비밀번호 안 맞음불안의파도타기.html 안 TEACHER_PASSWORD 확인
Apps Script 코드 수정 후

코드를 바꿨다면 반드시:

배포 → 배포 관리 → 연필 아이콘 → 새 버전 → 배포

「저장」만 하면 웹앱에 반영되지 않습니다.

11보안 안내

  • 학생용 URL: 학생에게 공유 OK
  • 선생님용 URL + 비밀번호: 상담교사만 보관
  • 시트: 본인 Google 계정 — 공유하지 않으면 본인만 열람
  • 다른 교사와 시트·URL·비밀번호를 같이 쓰지 마세요 (데이터 섞임)
