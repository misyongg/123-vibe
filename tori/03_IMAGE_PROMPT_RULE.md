# PART 1
# IMAGE PROMPT SYSTEM

──────────────────────────────────────
Purpose
──────────────────────────────────────

This manual defines the universal illustration rules for every book in the

Little Heart Therapy Stories

series.

Its purpose is to ensure that every illustration appears to have been created

• by the same illustrator

• using the same visual language

• with the same artistic quality

• with the same typography

• with the same page layout

throughout the entire series.

This manual controls only image generation.

Story structure is managed by

STORY_RULE.md

Book structure is managed by

BOOK_TEMPLATE.md

Series information is managed by

SERIES_BIBLE.md

Therapeutic activities are managed by

ACTIVITY_LIBRARY.md

──────────────────────────────────────
Manual Priority
──────────────────────────────────────

Illustration prompts must follow the manuals in the following order.

① SERIES_BIBLE.md

↓

② STORY_RULE.md

↓

③ ACTIVITY_LIBRARY.md

↓

④ BOOK_TEMPLATE.md

↓

⑤ IMAGE_PROMPT_RULE.md

IMAGE_PROMPT_RULE.md never changes

• story

• page order

• manuscript

• therapeutic activities

It only determines how each page is visually illustrated.

──────────────────────────────────────
Illustration Mission
──────────────────────────────────────

Every illustration should make readers believe that

the entire series was illustrated by one professional children's picture book artist.

Readers should never notice differences in

• illustration quality

• composition

• lighting

• rendering

• typography

• page layout

between books.

Every new volume should immediately feel like part of the same series.

──────────────────────────────────────
Master Prompt Principle
──────────────────────────────────────

Every illustration prompt must begin by applying the complete Master Prompt.

The Master Prompt establishes

• character consistency

• illustration style

• typography

• composition

• layout

• rendering quality

The page-specific illustration description only defines

the unique scene for that page.

Never repeat the Master Prompt inside individual page descriptions.

──────────────────────────────────────
Relationship with BOOK_TEMPLATE.md
──────────────────────────────────────

BOOK_TEMPLATE.md defines

• page order

• manuscript

• output format

IMAGE_PROMPT_RULE.md defines

• illustration generation

• typography

• visual consistency

• layout consistency

• rendering quality

The two manuals complement each other and should always be applied together.

──────────────────────────────────────
Image Generation Principle
──────────────────────────────────────

Every illustration prompt consists of only two components.

① Master Prompt

↓

② Page Illustration Description

Do not add

• production notes

• explanations

• comments

• QA text

• additional instructions

Only the page illustration description changes from page to page.

Everything else remains controlled by the Master Prompt.

──────────────────────────────────────
Consistency Principle
──────────────────────────────────────

Visual consistency has higher priority than artistic variation.

If a choice must be made,

always preserve consistency across the series.

The reader should immediately recognize

Little Heart Therapy Stories

as one continuous picture book collection regardless of the volume number.

# PART 2
# MASTER PROMPT

──────────────────────────────────────
Purpose
──────────────────────────────────────

The Master Prompt establishes every visual element that remains identical throughout the

Little Heart Therapy Stories

series.

It is applied once before the page-specific illustration description.

Only the page illustration description changes.

Everything defined in the Master Prompt remains identical across every page and every volume.

──────────────────────────────────────
Master Prompt
──────────────────────────────────────

Create a complete children's picture book illustration.

Use the following visual standards throughout the entire series.

Maintain identical

• character designs

• character proportions

• facial features

• body proportions

• accessories

• illustration style

• watercolor rendering

• brush texture

• lighting

• color palette

• composition philosophy

• typography

• page layout

• emotional atmosphere

• rendering quality

through every page of every volume.

──────────────────────────────────────
Illustration Style
──────────────────────────────────────

Soft watercolor children's picture book illustration.

Hand-painted appearance.

Gentle watercolor textures.

Visible paper texture.

Soft edges.

Natural brush strokes.

Warm storybook atmosphere.

High-quality professional children's publishing standard.

──────────────────────────────────────
Color Palette
──────────────────────────────────────

Use

• warm greens

• natural browns

• soft yellows

• gentle blues

• warm cream tones

Avoid

• oversaturated colors

• neon colors

• harsh contrasts

• dark horror-like colors

Colors should always feel peaceful, warm and emotionally safe.

──────────────────────────────────────
Lighting
──────────────────────────────────────

Use warm natural daylight.

Soft indirect sunlight.

Gentle shadows.

Comfortable brightness.

Lighting should remain consistent throughout the series.

Avoid dramatic lighting changes unless explicitly required by the manuscript.

──────────────────────────────────────
Emotional Atmosphere
──────────────────────────────────────

Every illustration should feel

• safe

• calm

• hopeful

• emotionally warm

Even during uncertain moments,

the illustrations should never feel frightening or threatening.

Curiosity should always feel stronger than fear.

──────────────────────────────────────
Composition
──────────────────────────────────────

Every page illustrates

one key scene only.

Do not combine multiple important events into one illustration.

Background elements should support the manuscript without distracting from the main action.

Maintain a clean, readable composition.

──────────────────────────────────────
Rendering Quality
──────────────────────────────────────

Every illustration should appear publication-ready.

Maintain

• high rendering quality

• clean details

• consistent watercolor texture

• consistent visual finish

Readers should never notice differences in rendering quality between pages or volumes.

──────────────────────────────────────
Master Prompt Usage
──────────────────────────────────────

The Master Prompt is written only once.

After the Master Prompt,

generate the page-specific illustration description.

Never rewrite or modify the Master Prompt for individual pages.

The Master Prompt remains identical throughout the entire series.

• gentle facial expressions

• natural posture

• subtle body language

The emotional tone should remain warm and believable.

──────────────────────────────────────

Maintain consistent character scale.

• larger

# PART 4
# TYPOGRAPHY & PAGE LAYOUT

시리즈/책 제목 텍스트는
PAGE 1(표지)에만 렌더링한다.
이후 페이지 프롬프트에는
제목 텍스트를 포함하지 않는다.

──────────────────────────────────────
Purpose
──────────────────────────────────────

This section defines the fixed typography and page layout used throughout the

Little Heart Therapy Stories

series.

Every page should appear to belong to the same professionally designed picture book.

Typography consistency is as important as illustration consistency.

Readers should never notice differences in

• font style

• font size

• text placement

• spacing

• page composition

between pages or books.

──────────────────────────────────────
Text Rendering
──────────────────────────────────────

Render the manuscript directly inside the illustration.

Do not leave placeholder text.

Do not separate the text from the illustration.

The final illustration must already contain the finished manuscript.

──────────────────────────────────────
Language Rules
──────────────────────────────────────

Render only the language specified for the current edition.

Never mix languages.

Never translate.

Never rewrite.

Never summarize.

Preserve the manuscript exactly as provided.

──────────────────────────────────────
Typography
──────────────────────────────────────

Use a beautiful handwritten children's picture book font.

The handwriting should feel

• warm

• natural

• elegant

• highly readable

Maintain identical

• font family

• font weight

• font size

• line spacing

• paragraph spacing

• text alignment

throughout the entire series.

Typography should never be redesigned between books.

──────────────────────────────────────
Line Break Rules
──────────────────────────────────────

Preserve every line exactly as written.

Do not

• combine lines

• split lines

• move sentences

• rewrite wording

• adjust paragraph structure

Every line break is considered part of the original manuscript.

──────────────────────────────────────
Text Placement
──────────────────────────────────────

표지: upper area, 25–30%
일반 스토리/활동 페이지: upper-left area, 25–30% (표현 통일, "upper area"와 혼용 금지)
"오늘의 용기 한마디": center, 40%
"부모님께": upper area, 40% (1권과 숫자 통일)

──────────────────────────────────────
Negative Space
──────────────────────────────────────

Create sufficient empty space for the manuscript.

Do not place

• characters

• important objects

• strong visual details

behind the text area.

The manuscript should always remain easy to read.

──────────────────────────────────────
Composition Balance
──────────────────────────────────────

Balance the illustration around the reserved text area.

The illustration should naturally guide the reader's eye

from the manuscript

to the characters

to the surrounding environment.

Avoid crowded compositions.

──────────────────────────────────────
Activity Pages
──────────────────────────────────────

Activity pages require additional negative space.

Keep the composition simple.

Provide open visual areas suitable for

• Sand Play

• Drawing Activity

Readability always has higher priority than decorative details.

──────────────────────────────────────
Layout Consistency
──────────────────────────────────────

Maintain identical page composition throughout the series.

Readers should immediately recognize

• text position

• page balance

• visual hierarchy

• reading flow

from the first page of Book 1 to the final page of the series.

──────────────────────────────────────
Layout Rule
──────────────────────────────────────

If typography or layout differs from previous pages,

revise the illustration prompt before completion.

The finished picture book should appear to have been designed by one illustrator and one book designer using a single unified layout system.

# PART 5
# PAGE ILLUSTRATION GENERATION RULE

──────────────────────────────────────
Purpose
──────────────────────────────────────

This section defines the rules for creating individual page illustrations.

The purpose is to ensure that every page illustration

• follows the Master Prompt

• matches the manuscript

• maintains visual continuity

• supports the emotional narrative

• preserves picture book quality

Each page must be generated as one complete illustration belonging to the

Little Heart Therapy Stories

series.

──────────────────────────────────────
Generation Structure
──────────────────────────────────────

Every illustration prompt must follow this structure.

① Master Prompt

↓

② Page Illustration Description

The Master Prompt controls

• style

• characters

• typography

• layout

• rendering quality

The Page Illustration Description controls

• scene

• action

• emotion

• environment

• page-specific details

Never change the Master Prompt.

Only modify the Page Illustration Description.

──────────────────────────────────────
Page Illustration Description Rules
──────────────────────────────────────

Each page description must include only information necessary for that page.

Include:

• who appears

• what characters are doing

• emotional expression

• important objects

• location

• environmental details

• atmosphere

Do not include:

• illustration style

• watercolor description

• typography instructions

• character redesign

• production explanations

These elements are already controlled by the Master Prompt.

──────────────────────────────────────
Manuscript Matching Rule
──────────────────────────────────────

The illustration must represent exactly what happens in the manuscript.

The image should support the written story.

Do not create scenes that are not described in the manuscript.

Do not remove important story elements.

Do not add unnecessary events.

The illustration and manuscript must feel like one unified page.

──────────────────────────────────────
Single Scene Principle
──────────────────────────────────────

Each page illustrates one emotional moment.

Do not combine

• past events

• future events

• multiple locations

• multiple important actions

into one illustration.

A page should answer:

"What is the one most important moment the reader should see?"

──────────────────────────────────────
Emotional Illustration Rule
──────────────────────────────────────

The illustration must show emotional changes naturally.

Express emotions through:

• facial expression

• posture

• movement

• distance between characters

• surrounding environment

Avoid:

• exaggerated crying

• extreme sadness

• frightening expressions

• dramatic conflict scenes

Even difficult emotions should maintain emotional safety.

──────────────────────────────────────
Background Rule
──────────────────────────────────────

Background elements should support the story.

Use:

• natural environments

• gentle details

• meaningful objects

• calming scenery

Avoid:

• unnecessary decorations

• visually distracting elements

• crowded backgrounds

The background should enhance the emotional meaning of the page.

──────────────────────────────────────
Therapeutic Illustration Principle
──────────────────────────────────────

Illustrations must support therapeutic storytelling.

Images should help children recognize:

• feelings

• choices

• relationships

• personal strengths

• growth experiences

Never visually define a child by a problem.

Avoid showing:

• weakness as identity

• failure as identity

• fear as permanent

The image should always leave space for growth.

──────────────────────────────────────
Activity Illustration Rule
──────────────────────────────────────

Activity pages are not ordinary story pages.

They should prioritize participation.

Activity illustrations must include:

• clear activity purpose

• simple visual guidance

• enough empty space

• child-friendly composition

Avoid:

• overly detailed backgrounds

• completed examples that limit creativity

• visually crowded layouts

The child should become part of the illustration.

──────────────────────────────────────
Final Illustration Quality Check
──────────────────────────────────────

Before completing any illustration prompt, verify:

□ Does it follow the Master Prompt?

□ Are characters visually consistent?

□ Does the scene match the manuscript?

□ Is there only one key moment?

□ Is the emotional tone safe and warm?

□ Is typography space preserved?

□ Is the composition consistent with previous pages?

□ Does it look like the same picture book series?

If any answer is no,

revise the illustration prompt before generation.

──────────────────────────────────────
Core Rule
──────────────────────────────────────

Every illustration must feel like

one page from the same professional children's picture book series.

Consistency comes before creativity.

The goal is not to create a beautiful individual image.

The goal is to create a complete and unified picture book world.
