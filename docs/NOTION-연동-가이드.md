# 상담 타이머 · 노션 + 구글 시트 연동 가이드

노션 토큰 발급(1~7단계)이 끝났다면, **8단계부터** 따라 하세요.

---

## 8단계: 구글 시트 만들기

1. [sheets.google.com](https://sheets.google.com) 접속
2. **빈 스프레드시트** 새로 만들기
3. 이름을 **`상담타이머 기록`** 등으로 변경
4. 이 시트는 나중에 상담 종료 시간이 자동 기록됩니다

---

## 9단계: 앱스 스크립트 붙여넣기

1. 구글 시트에서 **확장 프로그램 → Apps Script** 클릭
2. 기본 `Code.gs` 내용을 **전부 삭제**
3. 이 저장소의 `apps-script/Code.gs` 내용을 **복사해서 붙여넣기**
4. 왼쪽 **+** 버튼 → **HTML** 선택 → 파일 이름을 **`Timer`** 로 지정
5. `apps-script/Timer.html` 내용을 **복사해서 붙여넣기**
6. **저장** (디스크 아이콘)

---

## 10단계: 노션 토큰 등록

1. Apps Script 왼쪽 **프로젝트 설정** (톱니바퀴)
2. 아래로 내려 **스크립트 속성** → **스크립트 속성 추가**
3. 입력:

| 속성 | 값 |
|------|-----|
| `NOTION_TOKEN` | 노션에서 복사한 토큰 (`ntn_...`) |

4. **저장**

> ⚠️ 토큰은 절대 HTML이나 카톡에 공유하지 마세요.

---

## 11단계: 노션 DB 속성 이름 맞추기

`Code.gs` 맨 위 `CONFIG` 부분을 **본인 노션 DB**에 맞게 수정하세요.

```javascript
var CONFIG = {
  NOTION_DATABASE_ID: '1ad1b959-3ca0-8187-bc50-e94e057f408d',
  PROP_DATE: 'Date',        // ← 일정 날짜 속성명
  PROP_CASE: '케이스번호',   // ← 케이스 번호 속성명
  PROP_TYPE: '유형',         // ← (있으면) 유형 속성명
  ...
};
```

노션 DB 열 이름이 다르면 여기만 바꾸면 됩니다.

---

## 12단계: 노션 연결 테스트 (8번 확인)

1. Apps Script에서 함수 선택: **`testNotionConnection`**
2. **실행** ▶ 클릭
3. 처음이면 **권한 허용** (구글 계정으로 승인)
4. **실행 로그** 확인:

| 결과 | 의미 |
|------|------|
| `노션 연결 성공!` | ✅ 정상 |
| `401` / `unauthorized` | 토큰 오류 또는 DB 연결 안 됨 |
| `Could not find database` | DB ID 또는 Connections 미연결 |

**Connections가 안 됐을 때:** 일정표 페이지 → `···` → Manage connections → 상담타이머 연결

---

## 13단계: 시트 탭 준비

1. 함수 선택: **`setupSheet`**
2. **실행** → `상담기록` 탭이 생기고 헤더가 추가됩니다

시트 열:

| 기록일시 | 케이스번호 | 제목 | 유형 | 예정시작 | 실제시작 | 실제종료 | 소요(분) | 노션ID |

---

## 14단계: 웹앱 배포 (휴대폰에서 쓰기)

1. Apps Script 우측 상단 **배포 → 새 배포**
2. 유형: **웹 앱**
3. 설정:
   - 실행 계정: **나**
   - 액세스 권한: **나만** (본인만 쓸 때)
4. **배포** → URL 복사
5. 휴대폰 브라우저에서 URL 열기 → **홈 화면에 추가**

---

## 15단계: 사용 방법

1. 앱 열면 **오늘 노션 일정**이 자동으로 표시됩니다
2. 해당 일정을 **탭**하면 타이머가 시작됩니다
3. 예정 시간(0:00)에 알람이 울리며, **상담종료**를 누를 때까지 초과 시간이 표시됩니다
4. 상담 종료 시 **구글 시트에 자동 기록** (케이스번호 포함)
5. 수동으로도 초/중/고/학부모 버튼으로 시작 가능

---

## 자주 나는 오류

| 증상 | 해결 |
|------|------|
| 일정이 안 보임 | `PROP_DATE` 속성명 확인, DB Connections 확인 |
| Guest 워크스페이스 | Sailing 등 타인 워크스페이스는 관리자가 연동해야 함 |
| 시트 기록 안 됨 | `setupSheet` 실행 여부, 권한 허용 확인 |
| 상담만 보고 싶음 | `CATEGORY_FILTER: '상담'` + `PROP_CATEGORY: '일정 구분'` (일정 구분에 '상담' 포함 일정만) |

---

## 파일 구성

```
apps-script/
  Code.gs      ← 서버 (노션 읽기 + 시트 쓰기)
  Timer.html   ← 타이머 화면
index.html     ← 노션 없이 단독 사용 버전
```

노션 연동 없이 쓰려면 `index.html`만 열면 됩니다.
