# Google 시트 연동 설정 (선생님용)

**제작**: 전문상담교사 김미선 (misyongg)

학생이 기록 저장 시 **Google 스프레드시트**에도 자동으로 쌓이게 하는 방법입니다.

## 1. 스프레드시트 만들기

1. [Google 스프레드시트](https://sheets.google.com)에서 새 시트 생성
2. 이름 예: `오늘의 마음날씨 기록`

## 2. Apps Script 붙이기

1. 시트에서 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 전부 지우고, 이 폴더의 `Code.gs` 내용을 붙여넣기
3. **저장** (프로젝트 이름: `마음날씨` 등)

## 3. 웹 앱으로 배포

1. **배포 → 새 배포**
2. 종류: **웹 앱**
3. 설정:
   - **다음 사용자 인증 정보로 실행**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. **배포** → **웹 앱 URL** 복사  
   (형식: `https://script.google.com/macros/s/...../exec`)

## 4. 앱에 URL 연결

`consultation-card/config.js` 파일을 열고:

```js
const MOOD_WEATHER_CONFIG = {
  GOOGLE_SHEETS_URL: "여기에_복사한_URL_붙여넣기"
};
```

저장 후 `main`에 푸시하면 GitHub Pages에 반영됩니다.

## 5. 확인

- 브라우저에서 웹 앱 URL을 열면 `{"ok":true,"service":"mood-weather"}` 가 보이면 성공
- 학생이 앱에서 **오늘 기록 저장** → 시트에 `마음날씨기록` 탭에 행이 추가됨

## 시트 컬럼

| 날짜 | 시간 | 별칭 | 몸(에너지) | 기분(0-10) | 마음날씨 | 이모지 | 저장시각(ms) |

## 참고

- **별칭**은 학생이 스스로 정한 닉네임입니다 (실명 불필요).
- 폰에는 **내 별칭 기록만** 보이고, 선생님 시트에는 **전체 학생** 기록이 모입니다.
- URL이 비어 있으면 폰에만 저장되고 시트 연동은 건너뜁니다.
