# 불안 종이컵 — Google 시트 연동 (선생님용)

학생 쪽지와 상담 연동 기록이 **Google 스프레드시트**에 자동으로 쌓이게 하는 방법입니다.

## 1. 스프레드시트 만들기

1. [Google 스프레드시트](https://sheets.google.com)에서 새 시트 생성
2. 이름 예: `불안 종이컵 기록`

## 2. Apps Script 붙이기

1. 시트에서 **확장 프로그램 → Apps Script**
2. 기본 `Code.gs` 내용을 전부 지우고, `anxiety-cup-Code.gs` 내용을 붙여넣기
3. **저장** (프로젝트 이름: `불안종이컵` 등)

## 3. 웹 앱으로 배포

1. **배포 → 새 배포**
2. 종류: **웹 앱**
3. 설정:
   - **다음 사용자 인증 정보로 실행**: 나
   - **액세스 권한이 있는 사용자**: **모든 사용자**
4. **배포** → **웹 앱 URL** 복사

## 4. 앱에 URL 연결

`anxiety-cup/config.js` 파일을 열고:

```js
const ANXIETY_CUP_CONFIG = {
  GOOGLE_SHEETS_URL: "여기에_복사한_URL_붙여넣기",
  TEACHER_PASSWORD: "10042580"
};
```

저장 후 `main`에 푸시하면 GitHub Pages에 반영됩니다.

## 5. 확인

- 브라우저에서 웹 앱 URL을 열면 `{"ok":true,"service":"anxiety-cup"}` 가 보이면 성공
- 학생이 쪽지 제출 → `불안종이컵기록` 탭에 행 추가
- 선생님이 상담 마무리 → `상담연동기록` 탭에 분류·DBT·소감 저장

## 시트 탭

### 불안종이컵기록

| 저장시각 | 별칭 | 감정 | 생각 | 상황 | 처리완료 | noteId |

- **처리완료**: 상담 마무리 시 `Y`로 표시됩니다. 선생님 앱은 **미처리 쪽지만** 불러옵니다.
- **noteId**: 쪽지 고유 ID (상담 후 처리완료 표시에 사용)

### 상담연동기록

| 저장시각 | 별칭 | 쪽지수 | 다룰수있는불안 | 다룰수없는불안 | 선택DBT | 소감메모 |

- **다룰수있는불안 / 다룰수없는불안** 열은 JSON 배열 문자열입니다.

## 참고

- **별칭**은 학생이 스스로 정한 닉네임입니다 (실명 불필요).
- 선생님 앱 STEP 1에서 별칭으로 필터링해 해당 학생 **미처리** 쪽지만 꺼낼 수 있습니다.
- 상담 마무리(STEP 4) 시 이번에 꺼낸 쪽지는 자동으로 처리완료 처리됩니다.
- URL이 비어 있으면 학생 앱은 로컬 컵 카운트만 올리고, 선생님 앱은 예시 데이터로 UI 테스트가 가능합니다.
